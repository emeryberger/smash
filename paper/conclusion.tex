\section{Conclusion}
\label{sec:conclusion}

\sys demonstrates that the memory allocator is a natural point to
implement transparent memory compression.  By exploiting
allocator-level knowledge---object liveness, call-site patterns, and
size classes---\sys reduces RSS by 17--80\% on real applications with
no source changes required.

The evaluation reveals that the compression pipeline and allocator
design are synergistic.  A compress-only variant running atop an
unmodified system allocator achieves 32--61\% RSS reduction, while
\sys's allocator design further reduces RSS by 10--25\% on
large-object workloads and lowers pipeline overhead.  Among the allocator design
choices, zero-on-free contributes most, followed by external metadata
and arena segregation.
Dictionary compression, despite theoretical appeal, is net-negative
due to metadata overhead---a finding revealed only through systematic
experimentation.
