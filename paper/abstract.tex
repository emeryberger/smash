\begin{abstract}
This paper presents \sys, a drop-in memory allocator that
transparently compresses cold heap pages by exploiting domain
knowledge invisible to the rest of the system. \sys{} organizes
allocations by call site so that similar objects share pages At
compression time, it zeroes freed slots to increase compressiblility,
and applies \emph{JIT compression}: a return-on-investment model
selects between fast zstd-1 and high-ratio zstd-9 based on the
expected CPU cost and RSS savings for each page, with signal-based
decompression on~demand.

Across four applications---memcached, RocksDB,
SQLite, and Redis---\sys reduces resident set size (RSS) by 21--76\% with negligible throughput
impact. We show that \sys{}'s compression
pipeline and allocator design are synergistic: its pipeline achieves
20--61\% RSS reduction even atop an unmodified system allocator,
while its allocator-level page tracking is critical for workloads
like Redis where external VM scanning cannot detect cold~pages.
\end{abstract}
