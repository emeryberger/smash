\begin{abstract}
This paper presents \sys, a drop-in memory allocator replacement that
transparently compresses heap pages. \sys works by identifying cold
pages, which it compresses, performing signal-based decompression
on~demand.  \sys comprises a specialized, compression-friendly memory
allocator and a allocator-aware compressor.  \sys strictly separates
heap data and metadata, avoiding inadvertent touches to cold data. Its
allocation mechanism groups homogeneous objects (same sizes and call
sites) onto the same pages, yielding predictable
compressibility. \sys's compressor thread applies \emph{JIT
compression}, using a return-on-investment model to select between
fast zstd-1 and high-ratio zstd-9 based on the expected CPU cost and
RSS savings for pages from each group. It zeroes any freed slots just
before compression, further increasing compressibility. Across
four real-world, memory-intensive applications (memcached, RocksDB,
SQLite, and Redis), \sys reduces resident set size (RSS) by
\rssRedMin--\rssRedMax\% with negligible throughput impact.
