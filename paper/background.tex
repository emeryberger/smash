\section{Background and Motivation}
\label{sec:background}

\subsection{OS-Level VM Compression}

Operating systems compress inactive pages as a middle ground between
keeping them resident and swapping to disk.

\paragraph{macOS Compressed Memory.}  Since OS~X Mavericks
(2013), macOS compresses inactive pages using
WKdm~\cite{wilson1999case,apple2013compressed}, a 32-bit
word-granularity dictionary compressor designed for 4\,KiB
pointer-heavy pages.  \punt{On 16\,KiB ARM64 pages with text or
serialized data, WKdm achieves poor compression: only 1.01$\times$ on
JSON and 1.07$\times$ on key-value records
(Table~\ref{tab:algo_compare}).}

\paragraph{Linux zswap.}  zswap intercepts pages destined for swap
and compresses them into a memory
pool~\cite{jennings2013zswap}.  It supports LZ4 (default), LZO, and
zstd as backends.  zswap operates per-page with no cross-page context
and no knowledge of which bytes within a page are live allocator
objects.

\paragraph{Windows.}  Windows 10 compresses pages from the modified
page list using the Xpress
algorithm~\cite{microsoft2015compression}.

All three mechanisms treat each page as an opaque byte~array.

\subsection{What the Allocator Knows}

The allocator possesses three kinds of structural information that OS
compressors cannot exploit.

\paragraph{Object liveness.}  A slab page may contain a mix of live
objects and freed slots.  Freed slots hold stale data from their
previous occupant.  The OS compressor must compress this stale data;
the allocator can zero it first.

\paragraph{Allocation patterns.}  Objects allocated from the same
call site tend to have similar structure (same fields, similar
values).  The allocator can route these allocations to dedicated
pages.  The OS has no visibility into allocation~origins.

\paragraph{Access granularity.}  The OS tracks page access through
hardware accessed bits, which provide one bit per page.  The
allocator tracks which size class occupies each page, enabling
per-size-class compression policies that skip size classes whose data
does not compress~well.
